# Changelog

All notable changes to this public client/docs repository are recorded here.
(The hosted connector evolves independently; this tracks the repo.)

## [1.0.0] — 2026-06-13

- Initial public release of the Webotee AI Connect client + docs.
- `server.json` manifest (MCP registry format) → `https://app.webotee.com/mcp`.
- Setup guides for Claude, ChatGPT, Cursor, VS Code, Claude Code.
- Full tool catalog (`docs/tools.md`, 50+ tools) + generator (`scripts/gen_tools.py`).
- Python quickstart (`examples/quickstart.py`) and thin `webotee_mcp` SDK.
- Ready‑to‑paste client configs, OAuth docs, Docker bridge, daily smoke test.
